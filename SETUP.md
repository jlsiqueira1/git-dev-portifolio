# Setup Instructions for the Hello-World Project

## Prerequisites
- Ensure you have [Node.js](https://nodejs.org/) installed on your machine.
- You should have Git installed as well.

## Cloning the Repository
Open your terminal and run the following command to clone the repository:
```bash
git clone https://github.com/jlsiqueira1/git-dev-portifolio.git
```

## Navigate to Project Directory
Change to the project directory:
```bash
cd git-dev-portifolio/hello-world
```

## Installing Dependencies
Install the necessary dependencies:
```bash
npm install
```

## Running the Project
To run the project, use the following command:
```bash
npm start
```

Now you should be able to see the Hello World project running in your browser!
