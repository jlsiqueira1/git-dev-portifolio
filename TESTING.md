# Testing Procedures

This document outlines the testing procedures that should be followed to ensure the quality and stability of the application.  

## Types of Tests
1. **Unit Tests**: Tests for individual components to ensure they function as expected.  
2. **Integration Tests**: Tests to ensure that different components work together.  
3. **End-to-End Tests**: Tests that simulate user interactions and test the application as a whole.

## Running Tests
To run the tests, use the following command:
```bash
npm test
```

## Reporting Issues
If any tests fail, please create an issue in the repository with the details of the failure and steps to reproduce it.
